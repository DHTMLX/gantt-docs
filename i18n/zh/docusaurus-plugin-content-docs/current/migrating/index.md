# 迁移到 DHTMLX Gantt

这些教程帮助您将现有的 Gantt 应用从另一个 JavaScript 库迁移到 [DHTMLX Gantt](https://dhtmlx.com/docs/products/dhtmlxGantt/)。每个指南将介绍数据库模式的变更、服务器端 API 的更新，以及客户端集成，并附带一个对照演示仓库，包含原始实现和迁移后的实现。

## 可用的迁移指南

- [从 Bryntum 迁移到 DHTMLX Gantt](./from-bryntum)
- [从 Syncfusion 迁移到 DHTMLX Gantt](./from-syncfusion)
- [从 DevExpress 迁移到 DHTMLX Gantt](./from-devexpress)
- [从 Frappe 迁移到 DHTMLX Gantt](./from-frappe)

## 开始之前

- 演示项目使用 Node.js 20+ 版本和 MySQL 数据库。
- 按照 [安装指南](/guides/installation) 安装 DHTMLX Gantt。
- 有关服务器端集成模式，请参阅 [Server-Side Integration](/guides/server-side)。
