# Миграция на DHTMLX Gantt

Эти руководства помогут вам перенести существующее приложение Gantt из другой библиотеки JavaScript в [DHTMLX Gantt](https://dhtmlx.com/docs/products/dhtmlxGantt/). Каждое руководство охватывает изменения схемы базы данных, обновления API на стороне сервера и интеграцию на стороне клиента, а также сопутствующий демонстрационный репозиторий, который включает как оригинальные, так и мигрированные реализации.

## Доступные руководства по миграции

- [Миграция с Bryntum на DHTMLX Gantt](./from-bryntum)
- [Миграция с Syncfusion на DHTMLX Gantt](./from-syncfusion)
- [Миграция с DevExpress на DHTMLX Gantt](./from-devexpress)
- [Миграция с Frappe на DHTMLX Gantt](./from-frappe)

## Прежде чем начать

- В демо-проектах используются Node.js 20+ и база данных MySQL.
- Установите DHTMLX Gantt, следуя [руководству по установке](/guides/installation).
- Для образцов интеграции на стороне сервера см. [Интеграция на стороне сервера](/guides/server-side).
