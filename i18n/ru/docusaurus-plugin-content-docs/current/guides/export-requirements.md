# Модули экспорта: системные требования

Чтобы установить [модули экспорта](guides/export-modules.md) на собственный сервер, убедитесь, что ваша система соответствует требованиям каждого из приведённых ниже модулей.

## Сервис PDF/PNG/Excel {#pdfpngexcel-service}

### Обзор

Экспорт в PDF/PNG/Excel — кросс-платформенное приложение на Node.js, основанное на JavaScript.

Оно распространяется в виде исходного кода и образа Docker.

### Системные требования

<table class="dp_table">
  <tr>
  <th><b>Аппаратное обеспечение</b></th><th><b>ОС</b></th><th><b>Среда выполнения</b></th>
  </tr>
  <tr>
  <td>- 1 ядро CPU (разделяемое виртуальное ядро подойдет) - как минимум 500 МБ ОЗУ</td>
  <td>- Linux — Windows — macOS</td>
  <td>- Node.js v20 или новее или - Docker</td>
  </tr>
</table>


## Импорт и экспорт из MS Project и Primavera P6 {#import-and-export-from-ms-project-and-primavera-p6}

### Обзор

Экспорт в MS Project является приложением на базе .NET Core Framework, написанным на C# и работает на Windows, macOS, Linux.

Мы можем предоставить вам исходный код, который можно разместить на вашем собственном сервере или любом облачном провайдере.
Исходный проект совместим с MS Visual Studio 2022+.

  <td>- .NET Core 7.0+</td>
