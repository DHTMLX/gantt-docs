# Использование пакетов после истечения срока подписки

Платные пакеты Gantt — коммерческая JavaScript-библиотека (`@dhx/gantt`) и обертки фреймворков (`@dhx/react-gantt`, `@dhx/angular-gantt`, `@dhx/vue-gantt`) — размещаются в приватном реестре по адресу `https://npm.dhtmlx.com`. Доступ к этому реестру связан с вашей подпиской: как только она истекает, вы больше не можете устанавливать или переустанавливать эти пакеты через npm.

Версии, на которые вы имеете право по лицензионному соглашению, остаются ваши для использования. Чтобы продолжать устанавливать их после окончания подписки, создайте локальную резервную копию **до** истечения подписки.

:::tip
Сделайте это, пока ваша подписка активна — как только доступ к `npm.dhtmlx.com` исчезнет, вы больше не сможете загрузить пакеты.
:::

:::note
Это относится только к платным пакетам `@dhx`. Публичные `dhtmlx-gantt` (Community) и `@dhtmlx/trial-*` (evaluation) размещаются в публичном реестре npm и не затрагиваются.
::-

## Создание резервной копии ваших пакетов

### 1. Установите пакеты в временный проект

~~~bash
mkdir dhtmlx-backup
cd dhtmlx-backup
npm init -y
npm install <ваши-dhtmlx-пакеты>   # например, npm install @dhx/gantt @dhx/react-gantt
~~~

### 2. Упакуйте каждую библиотеку

Установленные библиотеки находятся в `node_modules/@dhx`. Для каждого пакета, который вы хотите сохранить, выполните `npm pack`:

~~~bash
cd node_modules/@dhx/<package-name>
npm pack
~~~

Это создаёт файл `.tgz` в текущем каталоге (например `dhx-gantt-9.0.10.tgz`). Скопируйте сгенерированные файлы `.tgz` в безопасное место — например в папку `./lib/` вашего проекта.

## Использование сохранённых пакетов

Указывайте локальные файлы `.tgz` в `package.json` вашего проекта вместо реестра:

~~~json
"dependencies": {
  "@dhx/gantt": "file:./lib/dhx-gantt-9.0.10.tgz"
}
~~~

Затем выполните `npm install` как обычно. npm разрешает зависимость из локального файла, поэтому доступ к реестру не требуется.

## Публикация в ваш собственный приватный реестр

Если у вас есть собственный реестр npm, вы можете перепубликовать сохранённые пакеты туда вместо ссылки на локальные файлы. Распакуйте пакет в новую папку (или скопируйте его из `node_modules/@dhx/<package-name>`), откройте его `package.json` и укажите `publishConfig` на ваш реестр:

~~~json
"publishConfig": {
  "registry": "https://your.registry.example.com"
}
~~~

Затем опубликуйте его:

~~~bash
npm publish
~~~

## Если вы пропустили окно резервного копирования

Если у вас не удалось завершить резервное копирование до истечения срока подписки, напишите нам по адресу [info@dhtmlx.com](mailto:info@dhtmlx.com) — мы отправим вам последние версии, на которые вы имеете право.
