# Migration zu DHTMLX Gantt

Diese Tutorials helfen Ihnen dabei, eine bestehende Gantt-Anwendung von einer anderen JavaScript-Bibliothek auf [DHTMLX Gantt](https://dhtmlx.com/docs/products/dhtmlxGantt/) zu migrieren. Jede Anleitung führt durch Änderungen am Datenbankschema, Aktualisierungen der serverseitigen API und die client-seitige Integration, mit einem Begleit-Demo-Repository, das sowohl die ursprüngliche als auch die migrierte Implementierung enthält.

## Verfügbare Migrationsleitfäden

- [Migration von Bryntum zu DHTMLX Gantt](./from-bryntum)
- [Migration von Syncfusion zu DHTMLX Gantt](./from-syncfusion)
- [Migration von DevExpress zu DHTMLX Gantt](./from-devexpress)
- [Migration von Frappe zu DHTMLX Gantt](./from-frappe)

## Bevor Sie beginnen

- In den Demo-Projekten werden Node.js 20+ und eine MySQL-Datenbank verwendet.
- Installieren Sie DHTMLX Gantt gemäß der [Installationsanleitung](/guides/installation).
- Für Muster der Server-Integration siehe [Server-seitige Integration](/guides/server-side).
