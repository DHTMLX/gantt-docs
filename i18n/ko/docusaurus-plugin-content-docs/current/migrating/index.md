# DHTMLX Gantt로의 마이그레이션

이 튜토리얼은 기존의 Gantt 애플리케이션을 다른 JavaScript 라이브러리에서 [DHTMLX Gantt](https://dhtmlx.com/docs/products/dhtmlxGantt/)로 마이그레이션하는 데 도움이 됩니다. 각 가이드는 데이터베이스 스키마 변경, 서버 측 API 업데이트, 클라이언트 측 통합을 단계별로 설명하며, 원래 구현과 마이그레이션된 구현을 포함하는 동반 데모 저장소를 제공합니다.

## 사용 가능한 마이그레이션 가이드

- [Bryntum에서 DHTMLX Gantt로 마이그레이션](./from-bryntum)
- [Syncfusion에서 DHTMLX Gantt로 마이그레이션](./from-syncfusion)
- [DevExpress에서 DHTMLX Gantt로 마이그레이션](./from-devexpress)
- [Frappe에서 DHTMLX Gantt로 마이그레이션](./from-frappe)

## 시작하기 전에

- 데모 프로젝트에서 Node.js 20 이상과 MySQL 데이터베이스를 사용합니다.
- [설치 가이드](/guides/installation)에 따라 DHTMLX Gantt를 설치합니다.
- 서버 사이드 패턴에 대해, [서버 사이드 통합](/guides/server-side)를 참고하세요.
